Cours ASM / SIMD / Interpréteur

Bachelor 3 GTECH (spécialité moteur), Gaming Campus. Mémoire → assembleur x86-64 → SIMD → interpréteur, jusqu'à un projet de machine virtuelle accélérée par le matériel.
ChapitreSujet
1. Mémoire Histoire, hiérarchie mémoire, caches, alignement et padding, registres, DOD (AoS/SoA), prédiction de branchement
2. Assembleur x86-64 Registres, instructions, pile, convention d'appel Windows x64, MASM dans Visual Studio, encodage des instructions, ARM64
3. SIMD Histoire, auto-vectorisation d'abord, SSE en profondeur, AVX2, AVX-512, CPU dispatch, NEON
4. Interpréteur Lexer, Pratt, analyse sémantique, stack vs registres (Lua 5), représentation des valeurs, dispatch, LuaJIT, assembleur maison
5. Le projet Cahier des charges, planning, grille d'évaluation, pièges fréquents
